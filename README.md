# Antimations

![Badge](https://img.shields.io/badge/discord-yedel-blue)

![GitHub Release](https://img.shields.io/github/v/release/Yedelo/Antimations?label=GitHub%20version)

![Modrinth Version](https://img.shields.io/modrinth/v/PSazs4Yz?label=Modrinth%20version)

Cancels swing and other animations on players. Packets will still be sent so the mod is safe to use for anticheats.

Use /antimations or the config button in the mod list to open the menu.

## Features

<details><summary>Swing Customization</summary>

- Cancel Creeper Ignition Swings
- Cancel Fishing Rod Swings
- Cancel Block Hit Swings
- Cancel Air or Entity Swings
- Cancel Block Interact Swings
- Cancel Other Player Swings

</details>

<details><summary>Item Reset</summary>

- Cancel Item Use Hand Resets
- Cancel Item Update Hand Resets
- Cancel All Hand Resets

</details>

<details><summary>Other</summary>

- Cancel Own Block Animations
- Cancel Third Person Block Animations
- Cancel Own Bow Animations
- Cancel Third Person Bow Animations
- Cancel Eating Animations
- Cancel Drinking Animations
- Cancel Own Limb Movements
- Cnacel Other Limb Movements

</details>
